# Stay — фронтенд для PythonProjectBooking (v2)

React + Vite. Современный интерфейс со светлой и тёмной темой (переключатель в шапке).

## Что умеет

- **Отели:** поиск, фильтр по звёздам, сортировка, карточки с фото
- **Страница отеля:** галерея, рейтинг по отзывам, удобства, номера, отзывы, карточка с ценой «от…»
- **Бронирование:** окно с датами, выбором числа гостей и расчётом стоимости
- **Регистрация и вход** по email (JWT), показ/скрытие пароля, автоматическое обновление токена
- **Профиль:** просмотр данных, **редактирование** (имя, фамилия, имя пользователя, страна, телефон, **фото**),
  вкладка «Бронирования», выход, удаление аккаунта

## Запуск

1. Бэкенд: примените патч из `backend-patch/` (см. `backend-patch/README.md`) и запустите:

   ```bash
   cd mysite
   py manage.py runserver
   ```

2. Фронтенд (в другом терминале, в папке этого проекта):

   ```bash
   npm install
   npm run dev
   ```

   Откройте http://localhost:5173

Если Django работает не на `127.0.0.1:8000`, поменяйте `BACKEND` в `vite.config.js`.
Валюта задаётся в `src/utils.js` (`CURRENCY`).

## Структура

```
src/
  api.js         запросы к Django, JWT, обновление токена
  auth.jsx       вход / регистрация / выход / профиль
  toast.jsx      всплывающие уведомления
  utils.js       форматирование дат, цен, склонения
  pages/         Hotels, Hotel, Login, Register, Profile
  components/    Header, Modal, BookingModal, ProfileForm, Avatar, Stars, Icons, ThemeToggle
  styles.css     все стили; цвета и радиусы в переменных :root
```
